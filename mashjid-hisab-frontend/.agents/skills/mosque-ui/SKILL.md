- One primary green. Green = income, red = expense. Nothing else uses those colors.
- Primary actions are solid buttons at top of page. Secondary are outline.
- Dashboard totals show no decimals; forms and reports do. Format via formatMoney().
- Bangla font: Hind Siliguri / Noto Sans Bengali.
- Quick-add flows open as a bottom sheet on mobile, dialog on desktop. Required fields: amount, category, date (default today).
- Use plain words from docs/PRODUCT.md terminology table.
